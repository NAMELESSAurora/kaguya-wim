## 1. 样片确立的设计语言（全片沿用）

### 1.1 一章 = 一个世界 = 一套"框"
每章固定四样东西，换章就整套换：
1. **地**：一张抽象 shader（MJ 定调 → 改写），全章持续，给连续性。
2. **主框**：故事发生的取景框。其の一 = Z Flip 竖折叠屏；Pre = 大头贴机；其の二 = 直播窗口。后面三章各定一个（§4）。
3. **字体家族 + 双语装置**（§1.4）。
4. **卡牌动作**（§1.3），每章不同。

### 1.2 空间与层次（从 Fate MAD 与 バカみたいに PV 学到的五条）
1. **插进景深之间**：每个画面至少四层深度：前景结构（相框、卡、甜点从镜头前划过）、人物、字、远墙（抽象地/巨大幽灵字）。字前面一定要有东西经过，否则字只是贴在画面上（Fate MAD 的 JUST/ONE/TOUCH：字在舞台桁架和人物之后、鸟群之前）。
2. **每帧 5–7 种不同"种类"的层**：地 · 结构（细线、角标、微型字）· 幽灵大字 · 主角 · 一个支撑家族（卡 / 甜点 / 贴纸）· 歌词 · 表面（闪粉、颗粒）。一拍或半拍换一到两层（バカみたいに 的节奏）。
3. **相机绕行、俯仰，不只推拉**；每个镜头运动都要有理由（看鞋就俯、唱"跪下"就仰、窗口转向哪句就绕向哪边）。
4. **真正的 3D 物体做转场和重音**：卡/筹码朝镜头飞过、一圈卡绕主体转、穿过环形隧道、卡墙翻成波（Fate MAD 的筹码、环形笼、光环隧道）。
5. **框中框带标题**：相框、海报、直播窗都要有自己的标题/角标（Fate MAD 的 THE HEAVENS OPEN）。

### 1.3 卡牌系统（全片主道具）
**何时用卡**：半身像（必须，卡框裁掉不完整的画面）、有截断的全身立绘、设计好的卡牌动作。**何时不用**：干净的全身立绘直接站在场景里，前后穿插。
**卡本身**：NAI 卡面背景 + 原样立绘（`tools/card.py`），三层景深（画 · 人 · 金属边框），SAR 全息光随角度走（彩虹衍射、蚀刻纹、烫金、线稿微浮雕、扫光、四芒星），Tsukuyomi 卡背（`tools/card_back.py`），棱彩厚度。
**不晃**：卡静止，**在节拍/音节上"卡"一下换角度**，光在那一下扫过。
**动作词汇表（每章只用其中两三种，全片不重复）**：

| 动作 | 读法 | 用在 |
|---|---|---|
| 插卡（半身像入画：抽出 / 抛入 / 旋入 / 翻开） | 特写 | 全片，人物特写的统一方式 |
| 抽卡（背面朝上绕行 → 每个音节翻一张 + 稀有度光爆） | 揭晓 | 副歌 1「おひめさま」·终段 |
| 发牌成扇 → 戳向镜头 | 撒娇 | 副歌 1「ねえねえ」 |

### 1.4 双语 fusion 词汇表（一段一种，不叠两行字幕）
其の一：短语后**行内 chip** + 一条线躺在地上/立成墙 · Pre：**大头贴标签贴纸**在短语下 · 副歌 1：直播窗**标题栏打出中文**（固定锚点），海报两种语言同尺寸，章戳内嵌译文 · 主歌 2（新）：**弹幕**（日文是主播字幕，中文是观众弹幕，弹幕可以被人物遮挡）· 副歌 2（新）：**卡背译文**（翻牌时正面日文、背面中文——"厚度"手法真的做成卡）· 桥段（新）：**甜点标签**（每件甜点挂小价签，日文品名 + 中文注）· 终段：**两种语言都上墙**，金银对调。

### 1.5 素材管线（不变，补两条）
人物定调 → NovelAI（标签、Transparent BG）；卡面背景 → NovelAI 场景（与立绘同画风）；氛围 → Midjourney 定调图 → 抽象 shader；小物件 → ChatGPT（风格图约束）；具体场景 → **原片素材**（同步段用同步时间）。Midjourney 目前被"设置用户名"弹窗挡住，需要你处理一下；在那之前氛围图也可以先用 NovelAI。

### 1.6 质量规则（这几轮你指出的，全片执行）
取景框一律圆角，画面不出框，转动的窗口里所有零件跟着转 · 拼接处不留缝（屏幕一整块）· 不用全屏纯色闪帧（UI 插入做成会动的横幅）· 人物不压扁 · 截断永远由框裁掉 · 卡不晃 · 卡之间不穿模（每张卡独占一个绘制层段）· 4×MSAA + 每帧 2 个抖动采样（成片 3–4 个）· 乱码字池不放方块类符号（像缺字）· 歌词卡在音节上（`timing_snap.json`）。

## 4. 分段方案（新段落按样片语言写；样片三段的修订单独列出）

### 冷开场 0:00–0:10.9「电波降临」
- **镜头**：夜空中一张 Tsukuyomi 卡背在远处缓慢自转（全片的"徽记"，后面会反复回来），镜头推向它；月徽发出同心信号圈（抽象 shader 光环）。
- **0:04.8 鼓进**：卡背翻开 = 标题卡（WORLD IS MINE / CPK! Remix，铬合金 Y2K 字标 + 竖排印章），标题字**乱码收束**（GMV）。同时接原片的七色电线杆（同步镜头外的原片段落，按 v1.1 选段）。
- **歌词**：开篇宣言做成"电波字"，中文译文作为来电显示附在下面。
- **层次**：远：抽象星空地；中：卡背与信号圈；近：电波字；最前：两三粒闪粉从镜头前过。
- **转出**：信号圈展开成绘卷的金色霞云（原位变形）。

### 前奏 0:10.9–0:28.7《竹取絵巻 ver.2026》
- **镜头**：横向长卷从右往左卷，18 s 一个连续运动，强拍微加速。卷是一个真实的 3D 长条，镜头有轻微俯仰，卷面有厚度。
- **画面**：霞云窗里嵌原片（竹林、彩叶、御帘→直播窗）。
- **每拍**：五位求婚者递上"難題 其の一～其の五"卡（全息卡，卡面是宝物：子安贝、龙珠、火鼠皮衣、玉枝、石钵），**每两拍一张插进 WISHLIST 0/5 栏**，计数跳动。
- **转出**：长卷卷成贝壳，啪地打开就是 Z Flip（子安貝 → 折叠屏），正落在「その一」。

### 主歌 1 / Pre 1 / 副歌 1（样片，已做；全片版还要补的）
- 主歌 1：开场接前奏的贝壳→折叠屏变形；「その三」的三个弹幕气泡改用卡背译文的预演（小卡）。
- Pre 1：保持现在的低谷；鼓回来时加入"信号格→卡背月徽"的预告。
- 副歌 1：最后一秒的低点（61.6–62.6）可以再加一层：窗口外的卡背在每拍亮一下；「いますぐによ」后两张卡飞过镜头直接接间奏的"钻进卡面"。

### 间奏 1:22.1–1:38.4 ツクヨミ 城市飞行
- **入口**（Fate MAD 光环隧道）：飞过镜头的那张卡在画面中心停住、放大，镜头**钻进卡面**，卡面变成一串同心卡环组成的隧道。
- **城市**：用原片的 Tsukuyomi 城市 CG 镜头做底，经 ASCII 渲染器"显影"（ASCII 来自图像，不来自 SVG）；方块一格格长出揭示（GMV）。
- **每拍**：「Hey」「Hey baby」切片各点亮一块霓虹招牌，招牌字就是这句，双语写在招牌的两面。
- **字环**：「Hey baby」排成 3D 字环（バカみたいに 的环形字变成立体），镜头从环心穿过。
- **转出**：最后一个鸟居后面是酸性 T 台。

### 主歌 2 1:38.4–1:55.1 其の三「火鼠の皮衣」· 酸性铬合金
- **地**：抽象液态金属 shader（酸性青柠 + 电光蓝 + 火橙），只写流体与反光，不写场景。
- **主框**：一张**时装海报相框**（框中框带标题 "KAGUYA COLLECTION 2030"）。
- **双语**：弹幕；日文是主播字幕，中文是观众弹幕，弹幕从人物身后穿过、偶尔被人物挡住。
- **「欠点？」**：同一张图逐拍换酸性配色（竖屏 MAD）。铬合金大字被 T 台上的立绘挡住一半（人物挡字）。
- **「聞いてる？」**：弹幕全部停住，只剩"……"，下一拍恢复。
- **「白いおうまさん」**：铬合金旋转木马（GPT 小物件），用关键镜头：每拍出现在新位置，地上留残影环；木马**穿过**这句字（GMV 物体穿字）。
- **「迎えに来て」**：唯一静止的一拍，酸性世界里露一眼银色月亮（伏笔）。
- **「かしずいて」**：镜头降到仰角，公主变成海报。
- **卡牌动作**：她的卡被叠成一座卡塔，每句一层；「手を取って」那一拍她把塔推倒，卡瀑布般洒向镜头。

### Pre 2 1:55.1–2:10.9
- 皮衣（海报相框）从边缘烧起来，烧纸边把画面烧开（不是硬矩形），露出余烬。
- 鼓抽掉的 4 小节：金银两色歌词在余烬里慢慢浮现（全片最软的一句），一张卡的边缘被火慢慢烧穿。
- 鼓回来：KASSEN 的旗帜一面接一面竖起，每拍一面。

### 副歌 2 2:10.9–2:41.4 其の四「蓬莱の玉の枝」· KASSEN 对决
- **画面**：原片 KASSEN 舞台素材作为窗口内容；窗口外是抽象光束地（金、朱红）。旗帜做前景结构层，字插在旗帜之后、人物之前（Fate MAD 的舞台景深）。
- **卡牌动作**：**金银两叠对洗**（riffle）：辉夜唱时金叠洗过来，八千代唱时银叠洗回去；**卡背译文**：钩子句的每个音节翻一张卡，正面日文，背面中文。
- **推し色**：荧光棒海金银对半，分界线随对唱推来推去。
- **「わかってない」× 多次（每次不同）**：①立方体每拍转一面 → ②字躺在地上，镜头掠过 → ③五张卡切成横条，每拍加一条（竖屏 MAD 六条眼睛）→ ④全屏海报。
- **A/B 频闪**：只在对唱最密的两小节，2–3 帧交替，全段不超过 2 次。
- **玉枝**：糖晶玉枝按拍生长；「Yeah」后在断点上碎成糖晶。

### 断点 2:41.4–2:43.5

### 桥段 2:43.5–3:01.8 其の五「仏の御石の鉢」· candy pop 梦（深谷）
- **入口**：侧面那条细线转回正面，是一张**菜单卡**，镜头钻进去。
- **画面**：草莓牛奶粉的地，软糖光泽；线稿**二拍一动**地抖（バカみたいに），画面最多 3 层，运动很慢。

### 终段 3:05.3–3:30.2 五宝集齐 · 三代公主
- **「当然です！」**：五张宝物卡从五章飞回，合成王冠环（3D 环，镜头从环心穿过）。
- **「世界で一番おひめさま」**：抽卡再来一次，但这次背面朝上的是**三张**：金、银、青（Miku 剪影卡：剪影升起后点亮）。荧光棒海先三色后全色。
- **双语**：两种语言都上墙，金银对调；墙纸重复「ずっと」。

- **结尾**：五宝卡全部朝镜头飞过（Fate MAD 的筹码），然后骤停。

### 尾奏 3:30.2–3:46.0

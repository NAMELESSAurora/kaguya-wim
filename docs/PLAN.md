## 0. 一句话

> 竹取物语里的辉夜姬向五位求婚者提出了**五个无理难题**；ワールドイズマイン里的公主殿下也列了一张**任性清单**（その一、その二、その三……）。
> 这支 MV 把这两张清单叠在一起：全片分成**五章**，每章是一个难题、一件宝物、一个世界。五件宝物凑齐的那一刻，"世界第一公主殿下"的称号同时落在辉夜、八千代和初音未来这三代公主身上。

你提的每个关键词都派给一个世界，并且都有来历，不是贴上去的风格：

| 你的关键词 | 在片中的出处 | 放在哪 |
|---|---|---|
| **Y2K（未来主义）** | 原曲 2008 年诞生在 niconico 年代，那是初音的老家；而电影设定在 2030 年左右的近未来。所以这里不做 2008 年的复古，而是 **Y2K futurism**：当年想象的未来（半透明果冻外壳、铬合金、液态金属、虹彩气泡、悬浮全息 UI），在 2030 年的电影里成真（v1.1，你的意见） | 其の一（主歌 1） |
| **电波系** | 字面意思：月亮发出电波，辉夜从**电线杆（電柱）**里出生；天线格数、信号圈、彗星 | 冷开场、贯穿全片的"信号"动机 |
| **酸性** | ツクヨミ 的霓虹、激光和夜店感；火鼠之皮衣烧起来的铬合金火焰 | 其の三（主歌 2） |
| **Candy pop** | 歌词本身就有草莓蛋糕、布丁；佛前石钵变成布丁碗 | 其の五（桥段） |
| **拼贴** | 平安绘卷、2008 年的网页、2026 年的元宇宙直播，三个时代的媒介叠在同一画面里 | 全片的版面方法 |
| **MAD 剪辑** | 原片片段（你提供），在设计好的框里卡点 | 副歌与高潮 |
| **PV 制作手法** | 3D 歌词变换、空间转场、每拍都有变化 | 全片 |
| **Miku fusion** | 三代"公主"共用的双马尾，青色 39 色，CPK! Remix 本身也有官方 Miku 版 | 见 §3 |

## 1. 对你想法的判断

**方向是对的，而且比一般的"风格堆砌"更有底子**：Y2K、电波、candy、酸性、拼贴在这首歌和这部片子里都能找到真实出处（上表）。最大的风险是这五种风格**同时满开、处处都用**，就会重蹈 Won't Let You v5 "设备越堆越乱、没有逻辑"的覆辙。所以这份方案的核心做法是：**一种风格只占一个世界、只表达一个意思**，靠章节切换来换风格，而不是在一个画面里五种一起上。

**撞车风险**（我看过了，要主动避开）：
- **官方 MV**（YouTube g6yAXqs7GpQ）：两张静态立绘、粉红/正红单色、圆形取景、超大粗体字（REMIX / その）、环形歌词、像素块。→ 我们**不做单色粉红**，不以圆形取景作为主框，立绘也不做成主体。
- **本篇演唱会片段**（rXcPRKriVsI）：黑色场馆、粉色同心光环、荧光棒海、青色激光、中央发光立方体。→ 这些是**原片自己的视觉语言**，我们在其の二直接继承（见 §2），但会放进拼贴框和 3D 空间里重新演出，不只是原样剪辑。
- 已经有一支播放量很高的 4K 现场 MAD（直接剪演唱会片段）。→ 我们的区别在于用章节制、多世界配色和平面设计来承载素材。

## 2. 从原片学到的东西（作为设计依据）

来源：CGWORLD 两篇制作访谈、本篇演唱会片段与官方 MV 的逐段抽帧。等你给我片段素材后，我会再按时间轴逐帧分析一遍。

- **两种渲染语言**：导演把**现实世界做得漫画化、喜剧化**，**ツクヨミ 则追求 CG 感的立体**（但大部分其实是手绘）。→ 我们沿用这条分界：现实素材配**漫画格、漫符、速度线**的平面拼贴；ツクヨミ 素材配**真实透视的 3D 空间**和激光。
- **ツクヨミ = 京都式和风城市 + 数字招牌 + 霓虹**；反复出现的动机有发光的鱼、激光、霓虹、荧光棒，以及鸟居和灯笼。
- **演唱会**：粉色舞台配会动的网格地板和**下落的 ASCII 字符**；另一种舞台是**竹笋粒子**加跟着音乐走的灯光；还有鸟居、带和柄的灯具、镜面、水盆里升起的灯笼、天守阁上的投影映射。
- **KASSEN（对决）舞台**：cel-shaded、低多边形、低饱和，像老一代社交游戏的画面，还有旗帜和火焰。→ 对应原作里的求婚者章节，正好放在其の四。
- **配色（从抽帧读取）**：演唱会是黑底，配热粉、青色激光和白色荧光棒；官方 MV 是粉红单色。
- **角色外形（从帧里读取，需要你确认）**：辉夜是金色长双马尾；八千代是白银双马尾、戴金色发饰（官方资料：ツクヨミ 的管理人，"8000 岁"）；彩叶是深紫发、弹键盘。**辉夜和八千代都是双马尾**，这就是和 Miku 融合最自然的接口。

### 2b. 原片里和这条音轨同步的演唱（v1.1 新发现，2026-11-23）
- 电影中《ワールドイズマイン》的演唱段**用的就是这条音轨，并且逐帧同步**：**电影时间 1:20:26.79 = 音轨 0:00**。同步一直持续到音轨约 **1:39.4**（间奏结束，电影 1:22:06 黑一帧后切到下一首歌）。我核对了「髪形」「その二」「三つの言葉」「世界で一番おひめさま」这几句的字幕，时间对得上。
- **这意味着**：冷开场、前奏、主歌 1、Pre 1、副歌 1、间奏这几段，可以直接用**对得上口型的演唱镜头**。规则是：唱歌的特写只能放在它在音轨上对应的时刻；其他时刻用不露口型的镜头（背影、远景、手、键盘、观众、舞台）。
- 同步段的镜头表见 `cache/film/wimlive_shots.json`（换算：电影时间 − 4826.79 s = 音轨时间）。这段原片自己的剪辑节奏：副歌 1 每个镜头的运动量中位约 20，比我 v1 定的目标高，所以 §9 已上调。
- **避免和高播放量的现场 MAD 撞车**：同步演唱镜头只作为"对口型的锚点"，必须放在我们设计的框和世界里（手机屏、发光立方体的反光碎片、直播窗、贴纸剪影），并且和剧情素材穿插，**不能整段照搬**。
- **原片自带的 Miku 色**：下一首歌（电影 1:22:07–1:23:17）的舞台整体是**青绿色调**。八千代的双马尾在青光下几乎就是 Miku（1:22:20–1:22:22、1:22:36–1:22:39）。这些镜头是现成的 fusion 素材，用在合唱句和终段的青色时刻；但这段的口型对的是别的歌，只取不露口型的那几帧。

## 3. Miku fusion 怎么做（分三层，从轻到重）

1. **颜色与时代（必做）**：青色 `#39C5BB` 在全片只有一个意思，就是**"这首歌本身 / 两人合唱"**。辉夜单唱用金色，八千代单唱用银白，两人合唱的歌词用青色。其の一的 2008 年 Y2K 世界就是 Miku 的年代。
2. **双马尾接力（必做）**：歌词「その一 いつもと違う髪形に気がつくこと」唱到"发型"时，同一个剪影的双马尾按拍换色，金、银、青依次出现。这就是 fusion 第一次亮相，而且正好落在讲发型的那句词上。终段副歌再用一次，作为呼应。
3. **初音本人（建议轻量出现）**：终段副歌"世界で一番おひめさま"时，三代公主同框，Miku 作为"第一代公主"以**青色剪影**站在两人身后，不抢戏。另外用 NovelAI 做 fusion 立绘：Miku 穿十二单/和装、带月亮元素（"竹取公主 Miku"）；辉夜和八千代各做一套带 Miku 元素的变体（青色发绳、耳麦造型的发饰）。人物识别色必须保留。

> 可选彩蛋（看你喜好）：桥段甜点队列里混进一根葱；片尾卡用"39"（サンキュー）。

**不做的事**：不往音轨里混 Miku 版人声，音源固定用这版。

## 5. 分段节拍表

符号：**每拍** = 每拍至少一个可见变化；**镜头** = 本段唯一的连贯镜头运动；**演出** = 歌词的"动作"；**转出** = 怎么离开本段。时间以你的 LRC 为准，这里先用测量的粗时间。

### 冷开场 0:00–0:10.9「电波降临」
- **画面**：深夜的藏青天空，一根电线杆，它的分段画成**竹节**；月亮发出同心信号圈（用 shader，像仪器画出来的精确线条，不是 SVG 平涂）。画面一角有一部翻盖机，天线格按拍从 0 格涨到 3 格。
- **0:04.8 鼓进**：电线杆从一个竹节里透出光（原作发光竹节的构图），接原片的**七色"ゲーミング電柱"**（0:04:50–0:05:10），前面是流星（0:04:05），再接彩叶抱起婴儿（0:06:23）。开头一两帧 glitch，那是月亮电波的第一次渗入（§13）。
- **演出**：开篇宣言以**电波字**登场，由信号扫描线扫出、带像素马赛克，八千代唱用银白、辉夜唱用金色。中文翻译作为"来电显示"附在下方。
- **标题** bar 4（0:08.9）：`WORLD IS MINE ／ CPK! Remix` 做成铬合金 Y2K 标志，和一枚竖排书法印章叠在一起（"三代目"之类，文案待定），用**扫描 + 错版套准**的方式入场。
- **转出**：月亮的信号圈展开成绘卷上的金色霞云（形状原位变形：圆圈→霞纹）。

### 前奏 0:10.9–0:28.7《竹取絵巻 ver.2026》
- **镜头**：一条横向长卷，**从右向左**卷动（绘卷的阅读方向），18 s 一个连续镜头，只在每小节的强拍上微微加速，没有停顿。
- **画面**：金箔纸和金色霞云做框。卷上把古代与现代缝在一起：竹林→电线杆林，老翁→彩叶（原片嵌在霞云窗里），御帘→直播窗口。
- **每拍**：五位求婚者依次递上宝物，各配一张"難題 其の一～其の五"卡，宝物是 GPT 做的 Y2K 小物件、贴纸风；每拍一件"啪"地插进卷尾的 **WISHLIST 0/5** 栏（Y2K UI）。
- **演出**：无人声，只有章节字作为字体纹理，用竖排明朝体做幽灵大字。
- **转出** bar 13：长卷尽头卷成一个贝壳形，啪地打开就是一部翻盖机（子安貝 → clamshell），正好落在「その一」。

### 主歌 1 0:28.7–0:45.5 其の一「燕の子安貝」· Y2K futurism（2030 的翻盖终端）
- **世界**（v1.1 改）：一台 2030 年的翻盖终端，设计语言是 Y2K 未来主义：半透明果冻外壳、铬合金铰链、发光边缘、屏幕上方浮起全息界面。手机挂件、大头贴、弹幕这些"可爱"元素都保留，但质感换成果冻、铬和虹彩，不再是 2008 年的实物复刻。地面用 shader 写，依据 MJ 定调图：液态金属 / 虹彩气泡 / 全息网格。
- **その一（发型）**：§3 的双马尾接力，同一个剪影按拍换成金、银、青。**原片在这句上正好是辉夜在玩自己的双马尾**（同步镜头，音轨 0:28.9–0:35），所以换色直接做在这个镜头上：发色抠出来按拍重新上色，金→银→青。剪影版留到终段呼应时用。（技术风险，v1.1 实测：舞台粉光把头发和皮肤染成相近的颜色，头发是色相 0–10°、饱和度 0.17–0.27，皮肤是 335°、0.06–0.10，单靠色相抠不干净。样片阶段改用分割模型做逐帧头发蒙版，比如 SAM2 视频分割，需要安装；不行的话退回 NAI 立绘来做。）
- **その二（鞋）**：镜头**下摇**（有理由：要看鞋），出现一张大头贴连拍：木屐/厚底高跷、未来式长靴、演唱会靴（原片），每拍一格亮起。
- **その三（三个词回复，两人合唱 → 青色）**：直播的弹幕回复，**三个气泡**按三拍依次弹出；中文翻译就藏在弹幕里，翻译即是"世界的回复"。这是全片第一次出现青色。画面里放原片同步的两人比 V 合唱特写（音轨 0:37.8–0:39.9），塞进手机屏幕。
- **右手（右手がお留守）**：不画手（遵守你的规则），用 **Y2K 的手形光标** 去点一个"手をつなぐ"按钮。
- **每拍**：手机界面的一层换掉（来信、闪烁、贴纸、换框），格数和电量按拍变化。
- **演出**：デコ文字（Hachi Maru Pop），加闪粉笔画写出来；**卡在音节上**，字逐个弹入并回弹。

| 尾奏 | 3 → 0.3 | ≤ 10 | 每拍熄一盏 |

参照：你之前给的 Fate MAD 是 1.3 → 12，中间有个 0.3 的谷；插画 MAD 是 4–21。

## 10. 技术路线

- **引擎**：fork 自《澪標》（`src/space.js` 真实透视平面舞台、`flat.js` 拼贴页、入场 FX 库）+ Won't Let You 的"字即建筑"+ dunhuang-ascii 的 ASCII 渲染器。
- **素材视频**作为 WebGL 视频纹理；剪影和抠图用 `~/.local/matte`，超分用 `~/.local/sr`。
- **渲染**：puppeteer 无头渲染 + 页内 WebCodecs，**1440p60**，48 kHz AAC 音轨。
- **QC**：`profile_video.py` 查冻帧，`jerks.py` 查抽搐，歌词覆盖审计（每句的开头、中间、结尾各截一帧），转场前后各 12 帧的帧条。
- **歌词时间**：用你的 LRC（最好是逐字 ELRC）作为句级时间，再用 Qwen3 ForcedAligner + 人声轨起音校准到音节；合唱段的钩子句按每块的强拍重新锚定。

## 13. 从剧情来的设计依据与剧透暗示（v1.1，依据 `docs/film-index.md`）

**片子自己就给了这些设计的出处**：
- **電波**：月人袭来时新闻报道的就是"**電波ジャック**"（1:26:16–1:27:03），数字招牌上全是月亮的影像。所以全片的 **glitch 只有一个意思：月亮的电波在渗进来**。它从冷开场的一两帧开始，随剧情逐章变强，到终段的"お迎え"达到顶点。它不再是装饰。
- **电线杆**：原片里是七色发光的"**ゲーミング電柱**"（0:04:50–0:05:10），旁白还专门戏仿了竹取物语的开头。所以冷开场的电线杆要用原片这根七色的，不是白光。
- **冷开场由八千代唱**，而原片的开场旁白也是八千代，开口就是竹取物语的第一句「今は昔」（0:00:26）。讲故事的人就是公主本人，这是第一个暗示。
- **"bad ending"**：辉夜读了竹取的绘本，说那是"超级 bad ending"，要自己做一个 happy ending（0:13:19–0:14:39）。→ WISHLIST 在五宝之外**藏着第六格「HAPPY END」**，全片都空着，只在最后一个音亮起（见下面"结尾"）。"任性公主"最大的要求就是一个好结局。
- **三条规矩**：彩叶给辉夜立过三条"家规"（0:22:31–0:23:15，辉夜还闹别扭说"不许无视我"）。→ 主歌 1 唱「その一／二／三」时，手机屏外围的漫画格（现实世界的画风）里同步翻出这三条家规：公主的规矩对彩叶的规矩，两张清单互相押韵。
- **求婚者**：直播弹幕刷"MARRY ME, KAGUYA!"，辉夜回"打赢 Iro P 就嫁"（0:45:02–0:45:44）；黑玛瑙寄来"竹取式 KASSEN"挑战书（0:53:52）。→ 副歌 2 的"王子大人"就是这些求婚者，弹幕以求婚潮的形式出现。而**真正的王子是彩叶**（「無口で無愛想なおうじさま」对应彩叶的镜头）。
- **辣妹**：辉夜进 ツクヨミ 时选的就是金发"ギャル"形象（0:25:06）。→ 其の三 的辣妹皮草 T 台有了出处。
- **排名**：冠军之路排名从 8910 位一路涨到 3006 位（0:40:09），最后按粉丝数拿下八千代杯（1:11:37）。→「世界で一番」就是 **No.1**：副歌 1 结尾，排名计数器跳到 1。
- **甜点与"没有味道"**：ツクヨミ 里尝不出味道（0:26:45）；月亮"没有味道也没有温度"（1:30:49）；八千代吃不了松饼，自称"**電子の海の歌姫**"（1:18:33），这正是 Miku 的称号。→ 桥段的甜点由八千代唱，她吃不到。所以甜点画成**隔着玻璃的像素甜点**，看得见吃不到，「我慢します」就有了分量。辉夜接唱「わたしだってやればできるもん」时，接十年后她有了实体、"一秒都等不了"要吃松饼的镜头（2:09:21），暗示结局。
- **片子自己的 Miku 线索**：搬家那段放的是《ハッピーシンセサイザ》（1:15:22），新家也叫这个名字；片尾曲是《ray》和《Melt》（2:10:29、2:15:21）；"電子の海の歌姫"。§3 的 Miku fusion 是在接片子自己的线，不是硬加。

**剧透暗示（你说可以暗示）**。核心秘密是**八千代就是辉夜**：她回月球后听到彩叶的歌，逆着时间赶回来，撞上巨石，落在 8000 年前；一路以灵魂的形态活过来，成了 ツクヨミ 的歌姬（1:57:34–1:59:19）。暗示的原则是：**第一遍看是设计，第二遍看是剧透**。

| 时刻 | 暗示做法 |
|---|---|
| 主歌 1「その一 髪形」 | 双马尾按拍从**金变成银**：第一遍看是 fusion，知道剧情的人会看出这是辉夜变成八千代 |
| 前奏绘卷 | 长卷尽头不是收尾，而是**接回卷首**（环形长卷），卷轴边上的年份计数器转过"8000" |
| 间奏城市飞行 | 发光的鱼群里混着**一只发光的海蛞蝓**（八千代自称"一直是海蛞蝓模式" 1:01:14；记忆里 8000 年前的辉夜就是一只海蛞蝓 2:03:42） |
| 主歌 2「迎えに来て」 | 那一拍的银色月亮，接月人第一次闯入舞台的镜头（1:24:56–1:25:42） |
| 终段「ふいに抱きしめられた」（八千代唱） | 设计层全部撤走，接**彩叶一把拉住八千代**（2:01:02）或记忆潜水里的"救救我"（2:03:31） |
| 终段「轢かれる 危ないよ」 | 那道光轨就是**逆时间飞船撞上巨石**的那一下（1:57:34–1:59:19），所谓"危险"其实是 8000 年的弯路 |
| 结尾 | 荧光棒熄灭，只剩电线杆和月亮；最后一个音上，**电线杆重新亮成七色**，WISHLIST 第六格「HAPPY END」亮起。她又出来了，这个循环有了好结局（呼应十年后的复活演唱会 2:09:33 和辉夜那句"这是 happy ending 吗？" 2:10:26） |
